# How to install on x.ai/bot

1. Open https://x.ai/bot
2. New → Create new Bot
3. Name: `Orchestrator`
4. Edit Profile → paste [bot/DESCRIPTION.md](../bot/DESCRIPTION.md)
5. Send [bot/FIRST-MESSAGE.md](../bot/FIRST-MESSAGE.md)
6. Let the bot create `~/orchestrator/` on its cloud computer
7. Keep using this bot as the only owner-facing chat

If the main chat gets long, duplicate the bot or open a task channel.
Do not keep stacking new domains into the same transcript.
